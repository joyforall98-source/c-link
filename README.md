# c-link
C-Link: 학생자치를 위한 두 웹앱을 한 주소에서 씁니다.

## 학생자치 의안정보시스템 (`/`)
학급회의·학생회에 낸 안건이 제안 → 검토 → 회의에 올림 → 결정(통과·고쳐서 통과·통과 못 함) → 학교에 전달 → 학교 답변 → 실천 완료까지 어디쯤 왔는지 기록하고 공개합니다. 국회 의안정보시스템처럼 안건 번호, 진행 기록, 투표 결과, 회의록을 함께 봅니다. 화면의 낱말은 학생이 읽기 쉬운 말로 씁니다. 학교 학생회와 학급회의 모두 쓸 수 있습니다.

- 가입 없이 코드로 들어옵니다: 공간 코드(보기), 제안 코드(학급·모둠 대표: 안건 내기, 투표하기), 임원 코드(안건 내기, 다음 단계로 넘기기, 회의록, 투표 진행), 관리 코드(선생님: 설정, 학교 답변)
- 안건에는 학급(모둠) 이름이나 '학생회 임원'과 역할만 남고, 학생 이름·연락처는 모으지 않습니다
- 찬반 투표 결과를 안건에 넣을 수 있고, 여러 선택지 투표는 아래 다섯 방법으로 셉니다

## 투표 방식 실험실 (`/vote/`)
공간 없이 바로 투표방(방 번호 6자리, QR)을 엽니다. 교사가 다수결·결선투표·순위 점수·좋아요 세기·일대일 대결 중 하나를 고르면 학생은 자기 기기에서 그 방법에 맞게 투표하고, 결과를 공개하면 1등이 크게 나옵니다. 실험실 탭에서는 예시 상황 4가지로 다섯 방법을 나란히 비교합니다. 투표방과 표는 2일 뒤 지워집니다.

## 배포 (Vercel + Supabase)
1. Supabase 에서 새 프로젝트를 만들고, SQL Editor 에 `supabase/schema.sql` 을 붙여 넣어 실행합니다.
2. 이 저장소를 Vercel 에서 Import 합니다.
3. Vercel 프로젝트 > Settings > Environment Variables 에 `.env.example` 의 세 값을 넣고 Redeploy 합니다.
   - `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`: Supabase > Project Settings > API
   - `SESSION_SECRET`: 아무도 모르는 긴 임의 문자열

## 점검
`node check.js` 로 두 앱의 서버 흐름과 권한을 메모리 저장소에서 확인합니다 (배포에는 들어가지 않음).
